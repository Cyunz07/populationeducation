# Grade 10 Population Education Tracker

A comprehensive web-based tracking system for Grade 10 Population Education coursework and assessments at Aarambha Academy.

## Features

- 📚 Track assignments, notes, and reading by chapter
- 📊 Dashboard with completion statistics and trends
- 📈 Visual progress charts (bar, line, and radar charts)
- 👥 Student management and records
- 📋 Term marks tracking and analysis
- 📱 Responsive design
- 💾 Browser-based data persistence

## Tech Stack

- React 18
- Recharts for data visualization
- Lucide React for icons
- CSS-in-JS styling

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Cyunz07/Populationeducation.git
cd Populationeducation
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.

## Deployment

This app can be deployed to Vercel, Netlify, or any static hosting service.

### Vercel (Recommended)
1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your GitHub repository
4. Deploy!

## Data Storage

All data is stored in the browser's localStorage. Data persists across sessions but is only available on the device where it was entered.

## Navigation

- **Students**: Add/manage student list
- **Assignment / Notes / Reading**: Log coursework by chapter
- **Term Marks**: Track assessment marks by term
- **Dashboard**: View class progress and trends
- **Student Records**: View individual student performance
